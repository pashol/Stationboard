# StationBoard: Your Personal Swiss Transit Display 🚌

An open-source real-time departure display for Swiss public transport, running on a tiny $15 screen.

## What It Does

StationBoard displays live train/bus departures from two stations of your choice using the Swiss Transport API. Bonus: Bitcoin price ticker in the footer.

## Features

🚇 Real-time departures from any Swiss station
📊 Bitcoin price display
🔋 Smart power management & adaptive brightness
⚙️ WiFi setup portal (no cables needed)
🔄 Wireless firmware updates
🎛️ One-button control (brightness, station switching, OTA)

## Get Started

**GitHub:** https://github.com/pascalwhoop/StationBoard
**Hardware:** ESP32-2432S028R (~$15)
**Latest Release:** https://github.com/pascalwhoop/StationBoard/releases

I built this because I wanted a glanceable display showing when my train leaves—no phone, no browser, just the info I need.
